# ProyectoFinalProgra3-OrganigramaEmpresarial
## Organigrama Empresarial

Sistema backend desarrollado en Spring Boot para la gestión de estructuras jerárquicas mediante árboles.

## Tema
Gerencia > Jefatura TI > Desarrollador

## Arquitectura
El sistema implementa:
- Motor de árboles desacoplado
- Estrategia Collections
- Estrategia Custom
- Persistencia Memory
- Persistencia PostgreSQL
- Persistencia MongoDB/Neo4j

## Tecnologías
- Java 17
- Spring Boot
- Maven
- PostgreSQL
- MongoDB / Neo4j
- OpenAPI
- GitHub
- Trello
