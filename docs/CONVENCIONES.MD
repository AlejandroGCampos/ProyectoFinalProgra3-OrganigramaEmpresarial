# Convenciones del proyecto

## Ramas

Formato:

feature/<ROL>-<descripcion>

Ejemplos:

- feature/A-core-openapi
- feature/B-postgres-setup
- feature/C-mongo-config
- feature/G-repo-structure

## Commits

Ejemplos válidos:

- docs: add project conventions
- chore: create base repository folders
- feat: add postgres initial script
- config: add postgres properties

Evitar:

- cambios
- wip
- prueba
- fix cosas

## Pull Requests

Cada PR debe incluir:

- Qué se hizo.
- Por qué se hizo.
- Evidencia.
- Link a tarjeta Trello.
- Revisor asignado.

## Trello

Backlog → To Do → Doing → Review → Done

Una tarjeta solo pasa a Done cuando su PR ya fue mergeado.
